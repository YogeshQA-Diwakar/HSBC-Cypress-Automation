# HSBC Cypress Automation

## Project Overview
Automated HSBC Login Page Validation using Cypress and Page Object Model.

## Scenarios Covered

1. Open HSBC India website
2. Validate HSBC Logo
3. Validate Home Page Title
4. Click Login
5. Validate Login Header
6. Validate Continue Button
7. Validate Continue Button Disabled
8. Enter Username
9. Validate Continue Button Enabled
10. Validate Remember Me Checkbox
11. Validate Tooltip
12. Open Tooltip Popup
13. Validate Username Header
14. Validate Close Button
15. Close Popup

## Technology Stack

- Cypress
- JavaScript
- Page Object Model
- Git
- GitHub

## Execute

npx cypress open
